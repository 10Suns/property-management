8 条操作路径逐一检查

路径1 ✅ 从参考表单创建
ReferenceForms → [+ 创建] → POST/forms → FormEditor(?form=X)
→ 调整检查项 → 表单就绪
路径2 ✅ 创建空白表单
ProjectDetail → [+ 创建空白表单] → POST/forms → FormEditor(?form=X)
→ 手动添加检查项 → 表单就绪
路径3 ✅ 编辑已有表单
ProjectDetail → [编辑] → FormEditor(?form=X)
→ 增删改检查项 → 自动保存
路径4 ✅ 从表单开始检查
FormEditor(form模式) → [信息录入] → POST/records
→ FormEditor(record模式) → 检查项锁定 → 录入结果
路径5 ❌ 从RecordList新增记录
RecordList → [+ 新增记录] → Modal列出系统模板
→ POST/forms(又创建一份表单!) → FormEditor(?form=&inspect=1)
→ 自动创建记录
路径6 ✅ 继续已有记录
RecordList → 点击已有记录 → FormEditor(?record=X)
→ 检查项锁定 → 继续录入
路径7 ✅ 打印空白表
ProjectDetail → [打印空白表] → PrintPreview
或 FormEditor → [打印空白表] → PrintPreview
路径8 ✅ 打印已填记录
PrintSelect → 勾选记录 → PrintPreview → 下载PDF

🔴 发现的 4 个逻辑问题

问题 1：RecordList「新增记录」弹窗列出的是系统模板，不是"我的表单"
代码位置：RecordList.vue:89 — api.get('/templates')
应该改为：api.get('/forms?project_id=' + projectId)
影响：用户已建好表单，但新增记录时看不到自己的表单，反而看到28套系统模板
问题 2：RecordList.createRecord 每次都创建新表单（重复表单）
代码位置：RecordList.vue:135-148 — createRecord() 内先 POST /forms，再跳转
后果：用户从 RecordList 新增记录时，系统自动创建一份新表单。如果用户之前在 ReferenceForms
已经创建过同模板的表单，现在就有了两份。反复操作会积累大量重复表单。
问题 3：ProjectDetail「我的表单」卡片缺少"信息录入"按钮
代码位置：ProjectDetail.vue:25-29 — 每个表单卡片只有 [打印空白表] [编辑] [删除]
用户想开始检查，得先点「编辑」进 FormEditor，再点「信息录入」— 多一步跳转
应该加上 [信息录入] 按钮，直接进入检查录入模式
问题 4：录入检查结果时，界面和编辑表单时几乎一样
代码位置：FormEditor.vue — form模式和record模式共用同一个页面
虽然检查项已锁定（canEditItems=false），但页面标题、布局都没变
用户可能不清楚自己是在"编辑表单"还是"录入结果"

核心业务规则确认

你的业务规则：

第1步 — 在「📁 参考表单」选模板 → 自动创建为「我的表单」→ 按需调整检查项
第2步 — 打印空白表，带去现场检查
第3步 — 回来后在「我的表单」→ 点「信息录入」→ 只能从我的表单里选 → 录入结果
第4步 — 保存记录，打印存档

关键约束：第3步录入时，不能看到参考表单，不能修改表单结构
