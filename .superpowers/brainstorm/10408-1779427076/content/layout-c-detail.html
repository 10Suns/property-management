当前方案

  • 顶栏：项目名（左） + 操作按钮 + 用户名（右）
  • 左侧 180px：导航标签 + 分隔区

  • 侧边栏宽度：180px 够吗？还是 200/220？

  • 顶栏操作按钮：放哪些？是否需要移到侧边栏？
  • 右侧内容区需要限制最大宽度吗？
